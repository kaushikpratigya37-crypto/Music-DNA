# 🌱 InAmigos Foundation — Digital Impact Platform

### ✨ One Mission. Many Hands. One Cause.

A modern and responsive digital platform created for **InAmigos Foundation**, designed to showcase its social initiatives, community impact, and opportunities for people to contribute.

The website brings together meaningful storytelling, interactive sections, and a clean visual experience to make the foundation's work more accessible and engaging.

## 🌍 Highlights

- 🌱 Foundation mission & vision
- 🤝 Community and volunteer engagement
- 📊 Impact statistics
- 💚 Social initiatives & projects
- 📸 Visual project gallery
- 🙌 Volunteer & donation call-to-actions
- 📱 Responsive design for different screen sizes
- ✨ Modern UI with smooth interactions

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- AI-assisted development using Claude

## 🎯 Purpose

This project focuses on using **technology and thoughtful design to amplify social impact**, helping visitors understand the foundation's work and encouraging them to become a part of the change.

> 🌱 **Small actions. Many hands. Meaningful impact.**
